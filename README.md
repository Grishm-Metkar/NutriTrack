# NutriTrack — Nutrition & Diet Management System

A web-based nutrition tracking application built with Python Flask.

🔗 **Live Demo:** [https://nutritrack-1vy4.onrender.com](https://nutritrack-1vy4.onrender.com)

## Features
- User Registration and Login
- Browse Food Database
- Nutrition Calculator
- BMI Calculator
- Dashboard
- Manage Foods (Add, Edit, Delete)

## Technologies Used
- Backend: Python Flask
- Database: SQLite
- Frontend: HTML, CSS, Tailwind CSS
- Security: Werkzeug



## 🚀 How to Run Locally

1. **Clone the repository**
   ```bash
   git clone https://github.com/Grishm-Metkar/NutriTrack.git
   cd NutriTrack

2. Install dependencies
pip install -r requirements.txt

3. Run the app
python app.py

4. Open browser and go to
http://localhost:5000
